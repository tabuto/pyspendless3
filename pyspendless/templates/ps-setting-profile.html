Token personali (connettore Claude)

Servono ad autenticare il server MCP di PySpendless, per registrare spese parlando a Claude.

Attenzione:
  • Il token viene mostrato una sola volta: in database ne resta solo l'impronta, non è recuperabile in seguito.
  • Ha validità 365 giorni dalla generazione.
  • Chi possiede il token può registrare movimenti sull'account di famiglia: trattalo come una password.
  • Per sostituirlo va rimosso e riaggiunto anche il connettore lato Claude: le sue impostazioni di autenticazione non sono modificabili.
In Claude: Connettori → Aggiungi connettore personalizzato → questa URL, autenticazione «nessun accesso» e header authorization con valore Bearer <token>. In alternativa x-api-token, x-api-key o x-auth-token con il solo token.
